# PerformAX downloads

PerformAX is PerformAI's video analysis app for coaches and athletes: record or import a clip, go through it frame by
frame, draw on it, measure joints with the goniometer, compare two attempts, and, with a PerformAI plan, see
PerformAI's skeleton, joint angles and speeds. Sign in with your PerformAI account (the same as on the web
dashboard at [app.performai.tech](https://app.performai.tech)).

This page only holds the app's installers; the app's code is private.

## Android

**[Download PerformAX for Android (.apk)](https://github.com/performai-tech/performax-releases/releases/latest/download/PerformAX.apk)**
(always the newest version)

<img src="qr-android.png" alt="QR code: the Android download link" width="180">

1. Open the link on the phone (or scan the code with its camera) and download the file.
2. Open the downloaded file. The first time, Android asks to allow installing apps from your browser: allow it.
3. Open PerformAX and sign in.

To update, download from the same link again: it installs over the old version and keeps your videos.

## iPhone

**[Join the PerformAX beta on TestFlight](https://testflight.apple.com/join/xS9bQ5wJ)**

<img src="qr-iphone.png" alt="QR code: the TestFlight link" width="180">

1. Install **TestFlight** from the App Store (Apple's free app for beta apps).
2. Open the link on the iPhone (or scan the code) and tap **Accept**, then **Install**.
3. Open PerformAX and sign in. TestFlight installs new versions automatically.
